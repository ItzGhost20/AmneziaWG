# AmneziaWG Config Generator
ابزاری ساده و تحت وب برای تولید و شخصی‌سازی کانفیگ‌های AmneziaWG با استفاده از آی‌پی‌های تمیز کلودفلر.

🔗 ورود به برنامه (Live Demo)

💻 قابلیت‌های کلیدی:
🔍 آی‌پی‌های تمیز: دریافت خودکار و پویای آی‌پی‌های تمیز کلودفلر (Warp).
⚙️ تنظیمات پکت‌ها (Junk Packets): قابلیت تنظیم مقادیر jc ،jmin و jmax در سه حالت سبک، سنگین و دلخواه.
⚡ پشتیبانی از Amnezia 1.5: امکان فعال‌سازی و مقداردهی پارامترهای پیشرفته آمینزیا (I1-I5).
🚀 نحوه استفاده:
به لینک وب وارد شوید.
آی‌پی تمیز مورد نظر خود را انتخاب یا وارد کنید.
تنظیمات پکت‌ها و MTU(پیشفرض1280) را به دلخواه تغییر دهید.
تیک فعال سازی پارامترهای امنزیا ۱.۵ را روشن کنید.
روی دکمه ساخت کانفیگ کلیک کرده و فایل خروجی را دانلود یا کپی کنید.
بعد از کپی کانفیگو کپی کنید + بزنید بعد insert بزنید کانفیگ اضافه میشه استفاده کنید(اگر دانلود کردی بعد از زدن + روی file with connection settings بزنید و کانفیگ دانلود شده انتخاب کنید)
